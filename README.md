# Kẹm · Map 2D · Web 3D / 4D

Bản đồ hành trình **2D** + lớp web **3D** (Three.js particles, shader boot, GSAP):

- **MapLibre** flat 2D + lộ trình OSRM
- **Cinema 4D** follow path trên map phẳng + time scrubber
- **Three.js** atmosphere + shader boot
- Nhạc nền *Đi Giữa Trời Rực Rỡ*

## Chạy

```bash
npm install
npm run dev
```

Phím tắt: `Space` = Cinema 4D · `←/→` = điểm dừng.
